```
你的能力地图                    项目需求
───────────────                ───────────────
```

## 第 0 阶段：Python 地基补强（W1-W3）🔴 致命优先

> 目标：从"略懂"到能流畅读懂、改写、调试本书所有 Python 代码。**这一步省不掉，否则后面全卡。**

### W1：Python 核心语法 & 与 Java 的对照
- **学**：变量/类型、控制流、函数、列表/字典/集合/元组、文件 IO、异常处理
- **对照迁移法**（你的优势）：Java 的 class/interface → Python 的 class/ABC；Java 的 try-catch → Python 的 try-except；Java 的 List<Map> → Python 的 list[dict]
- **动手**：把 Ch1 的 `FirstAgentTest.py` 逐行读懂，不看教程能复述每行作用
- **产出**：一个你自己写的「天气查询」Python 小脚本（用 requests 调 wttr.in）

### W2：Python 进阶特性（本书高频用到的）
- **学**：
  - **装饰器** `@staticmethod`/`@property`/自定义装饰器（Ch7 框架大量使用）
  - **类型注解** `Optional[str]`, `List[Dict]`, `Callable`（本书代码全用类型注解）
  - **f-string 与字符串处理**（Agent 的 prompt 拼接核心）
  - **`dataclasses` / `pydantic`**（Ch7/13 数据建模核心，类比 Java 的 POJO + Lombok）
  - **`with` 上下文管理器**（资源管理）
- **动手**：用 pydantic 写一个「用户订单」数据模型，类比你会怎么用 Java 写

### W3：Python 异步 & 工程化（Ch7/9/11 必备）
- **学**：
  - **async/await** 协程基础（Ch7 异步工具、Ch11 分布式训练）
  - **模块与包**结构（`__init__.py`, 相对导入）
  - **虚拟环境** venv/uv + pip（参考 `Extra07-环境配置.md`）
  - **测试** pytest 基础（Ch7 有 `test_*.py`）
  - **`.env` + python-dotenv** 环境变量管理
- **动手**：搭建本书统一环境——Python 3.10+ venv、安装 `openai`/`requests`/`python-dotenv`、注册 AIHubmix 或 ModelScope 拿 API Key（按 `Extra07` 操作）、跑通 `FirstAgentTest.py`

### W18-W19：Ch10 智能体通信协议 🟢 你的绝对主场 🔴🔴
> **MCP / A2A / ANP 三个协议**——本质都是「Agent 如何像 Web 服务一样对外提供/消费 API」。这是为你量身定做的章节。

- **读**：`docs/chapter10/第十章 智能体通信协议.md`
- **MCP（Model Context Protocol）**（最重要，行业新标准）：
  - 用 MCP 客户端调社区服务器（GitHub MCP、天气 MCP）
  - 理解 5 种传输方式：memory/stdio/HTTP/SSE/StreamableHTTP
  - **动手建自己的 MCP 服务器**：`code/chapter10/my_mcp_server.py` + `weather-mcp-server/` 包（含 Dockerfile，可上 Smithery）
  - **你的优势**：MCP 服务端本质就是一个 HTTP/RPC 服务，用你 7 年 Web 服务经验对照，秒懂
- **A2A（Agent-to-Agent）**：Agent 作为服务暴露、多 Agent 协作/谈判、客服路由
- **ANP（Agent Network Protocol）**：服务发现、能力匹配、任务分发、负载均衡（类比微服务注册中心）
- **产出**：建一个自己的 MCP 服务器（比如包装一个你熟悉的 Java API），Docker 化部署

### W20-W21：Ch11 Agentic-RL 🔴🔴🔴 全书最硬核
> 你有本地 GPU，按完整实战学。但需要先补 ML/DL 基础。

- **预备（W20 前半周）**：补深度学习最小必要知识——反向传播、梯度下降、PyTorch 基础、LoRA 原理、PPO→GRPO 演进（看 3B1B 神经网络系列 + 李宏毅 RL 课 2-3 集）
- **读**：`docs/chapter11/第十一章 Agentic-RL.md`
- **代码**（`code/chapter11/`）：
  - `00_quick_test.py` → `08_distributed_training.py` 共 9 个脚本
  - **SFT 监督微调** + **LoRA**（参数高效微调，r=8/alpha=16）
  - **GRPO**（Group Relative Policy Optimization，KL 系数=0.1）
  - 数据集：`openai/gsm8k` 数学推理
  - 基座模型：`Qwen/Qwen3-0.6B`（你的 GPU 能跑）
  - 分布式：DeepSpeed ZeRO-2/ZeRO-3（`accelerate_configs/`）、DDP
  - 超参搜索：网格 + Optuna
  - 部署：LoRA 合并、8-bit 量化、FastAPI + uvicorn 服务化
- **监控**：TensorBoard + 可选 W&B
- **产出**：在你的 GPU 上完整跑通一次 SFT→GRPO 训练 Qwen 小模型，并部署成 API 服务
- **心态**：这是全书唯一可能让你想放弃的章节。允许慢，允许调参失败，理解原理比跑出 SOTA 更重要
