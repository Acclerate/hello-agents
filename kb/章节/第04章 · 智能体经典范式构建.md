ReAct 的循环结构？::Thought（推理下一步）→ Action（调工具）→ Observation（结果回填）交替直至给出最终答案

Plan-and-Solve 相比 ReAct 的取舍？::先规划全局再执行，长任务不易跑偏；但计划可能过时，需要执行中修正

Reflection 解决什么问题？::让 Agent 用 LLM 批评自己的输出并迭代，无需外部反馈信号即可提升质量
