# Agent≠Chatbot

> [!info] 一句话定义
> Chatbot 的产出是"一段文本"，Agent 的产出是"环境中的改变"：有目标、有循环、有工具、有终止条件——这决定了架构差异，不是 prompt 差异。

## 🎯 核心概念

### 是什么
- Chatbot：一问一答，状态基本只靠对话历史，答完即止
- Agent：**目标驱动的主循环**（感知→决策→行动→观察）+ 工具改变外部世界 + 状态跨轮次延续 + 明确的停止条件
- 判断口诀：把它放到对话之外，它还能"做"什么？什么都不能 → Chatbot

### 为什么重要
- 决定架构选型：Agent 需要 loop、工具层、记忆与上下文管理、评估闭环，Chatbot 只需对话管理
- 决定评估方式：Chatbot 看单轮回答质量；Agent 看任务成功率与代价（步数/token/工具调用）
- 来自 [[PITFALLS-GUIDE]] 第三篇：转行者最常把"接了 API 的对话程序"当成智能体

## ⚠️ 易错点 & 陷阱
- ❌ 常见误解：把系统提示写得"像个助理"就是 Agent
- ✅ 正确理解：没有行动通道（工具/环境）与循环，就永远是 Chatbot
- ❌ 工具调用 ≠ 函数调用：前者是 Agent 的决策行为，后者只是代码语法
