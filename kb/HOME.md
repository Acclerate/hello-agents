# 🚀 快速开始 · Hello-Agents 知识库

> 欢迎！本库基于 Datawhale 开源教程《**从零开始构建智能体（Hello-Agents）**》（16 章正文 + 74 个配套实验 + 3 个综合项目 + 14 篇社区扩展），用 Obsidian 把全书织成可检索、可复习、可打卡的学习网。

## 🎬 30 秒上手

### 想学一章
- 打开 [[MOC - Hello-Agents 知识体系]] 找到位置 → 读章节笔记 → 点链接进正文 → 把 frontmatter 的 `status` 改为 `已掌握`
- 每章笔记底部有闪卡，直接进入间隔复习队列

### 想拆一个实验
1. 在 `kb/练习拆解/` 新建文件（自动套 `tp-练习拆解` 模板），或对 `code/learn/` 的练习建 `[[练习 W1-01 · 基础语法复盘|练习拆解卡]]`
2. 按「**目标 → 运行观察 → 对照验收 → 沉淀**」四步走

### 想复习（间隔重复）
- 左下角状态栏点「待复习」数字，或 `Ctrl+P` → `Spaced Repetition: Review flashcards`
- 闪卡已按 `#flashcards/ha/基础`、`#flashcards/ha/构建` 等五部分分组（内嵌在章节/概念笔记里）

### 想搜全书
- `Ctrl+P` → `Omnisearch` 输入关键词秒搜；英文镜像、共创项目内部、图片目录已从搜索中排除

## 💡 核心心法

> **范式先于框架，评估先于堆料。** 任何 Agent 系统，先分清决策（LLM）、状态（记忆/上下文）、能力（工具）三件事；能复用的范式不要重写，能评估的效果不要靠感觉。
