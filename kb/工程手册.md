# 🛠️ 工程手册 · 环境、运行与知识库维护

## 🐍 环境准备

- conda 环境：`conda activate hello-agents`（Python 3.10+，CUDA 可用于第 11 章训练）
- API Key：各章脚本从 `.env` 读取（见 `code/chapterN/.env.example`）。首次配置参考 [[ENV-REPORT]] 与 [[Extra07-环境配置]]
- n8n / Node.js 安装（第 5 章）：[[N8N_INSTALL_GUIDE]] · [[NODEJS_INSTALL_GUIDE]]

## ▶️ 各章代码运行要点

| 章 | 目录 | 运行方式 | 备注 |
| --- | --- | --- | --- |
| 1 | `code/chapter1/` | `python FirstAgentTest.py` 或打开 notebook | 需 API Key，已跑通 ✅ |
| 2 | `code/chapter2/` | `python ELIZA.py` | 纯规则，无需 Key |
| 3 | `code/chapter3/` | 逐个运行 `N_gram.py`、`BPE.py` 等 | Transformer 较吃算力 |
| 4 | `code/chapter4/` | `python ReAct.py` 等 | 需 API Key（`llm_client.py` 为公共封装） |
| 5 | `code/chapter5/` | 平台导入 `.zip/.yml/.json` | 无本地脚本，见各平台导入向导 |
| 6 | `code/chapter6/<框架>/` | 各 Demo 目录独立 requirements | `pip install -r requirements.txt` 后运行 |
| 7 | `code/chapter7/` | `python my_main.py`；`pytest` 跑测试 | 测试文件在本地未入库（`.gitignore`） |
| 8-12 | `code/chapter8..12/` | 按编号顺序运行脚本 | 多数需 API Key；11 章需 GPU |
| 13 | `code/chapter13/helloagents-trip-planner/` | backend `python run.py`；frontend `npm i && npm run dev` | 前后端分离 |
| 14 | `code/chapter14/helloagents-deepresearch/` | backend `uv sync && uv run ...`；frontend npm | uv 管理依赖 |
| 15 | `code/chapter15/Helloagents-AI-Town/` | backend `python main.py`；Godot 打开前端工程 | 见 [[SETUP_GUIDE]] |

## 🧹 维护本知识库

### 刷新实验索引（幂等）

```bash
python scripts/gen_kb_index.py          # 按 scripts/kb_manifest.yaml 重新生成 kb/实验/
python scripts/gen_kb_index.py --check  # 只校验 manifest 中的文件是否真实存在
```

- 实验卡完全由脚本生成（文末有 `generated by` 标记），**不要手改**；改 `scripts/kb_manifest.yaml` 后重跑
- 章节/概念/练习拆解笔记是手工内容，脚本不会触碰
- 新增章节实验：在 manifest 对应章节点下追加条目即可

### 笔记约定

- frontmatter：`type`（章节/概念/实验/项目/练习拆解/MOC/看板/导读）、`status`（未开始/进行中/已掌握）、`chapter`、`difficulty`（1-5）、`review_dates`
- 链接：md 笔记用 `[[wikilink]]`（最短路径）；代码等非 md 文件用相对 markdown 链接
- 闪卡：`#flashcards/ha/<篇章>` 标签 + `问题？::答案`（Spaced Repetition 插件语法）

### Vault 配置（.obsidian/）

- 插件四件套：dataview、templater、spaced-repetition、omnisearch（已随仓库提交，克隆即用）
- `userIgnoreFilters` 排除：英文镜像、`_sidebar`、Co-creation-projects/、图片目录、`.zcode/` 等
- `workspace.json` 已 gitignore（本机窗口状态不入库）
