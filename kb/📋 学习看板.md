# 📋 学习看板

> 这里是整个知识库的「控制中心」。章节与概念的掌握状态、实验与练习进度都在这里一览无余。
> 用法：学完一篇笔记，把 frontmatter 的 `status` 改为 `已掌握`，并在「📅 复习记录」追加日期，本页自动更新。

## 🎯 概念状态总览

```dataview
TABLE
  category AS "篇章",
  difficulty AS "难度",
  status AS "状态",
  length(review_dates) AS "复习次数",
  created AS "创建"
FROM "kb/概念"
WHERE type = "概念"
SORT difficulty DESC, status ASC
```

## 🔴 待学习 / 未复习

```dataview
TABLE type AS "类型", difficulty AS "难度", file.link AS "笔记"
FROM "kb/章节" OR "kb/概念"
WHERE status = "未复习" OR status = "未开始" OR status = "进行中"
SORT difficulty DESC
```

## 🟢 已掌握

```dataview
LIST
FROM "kb/章节" OR "kb/概念"
WHERE status = "已掌握"
```

## 📚 章节进度

```dataview
TABLE
  difficulty AS "难度",
  status AS "状态",
  length(review_dates) AS "复习次数"
FROM "kb/章节"
WHERE type = "章节"
SORT chapter ASC
```

## ✏️ 练习拆解进度

> 用 `tp-练习拆解` 模板在 `kb/练习拆解/` 新建拆解笔记，走「目标 → 运行 → 对照验收 → 沉淀」四步。

```dataview
TABLE
  week AS "周",
  status AS "状态",
  created AS "创建"
FROM "kb/练习拆解"
WHERE type = "练习拆解"
SORT week ASC, file.name ASC
```

## 🔬 实验索引汇总（自动生成，77 项）

```dataview
TABLE WITHOUT ID
  "第 " + chapter + " 章" AS "章",
  length(rows) AS "实验数",
  filter(rows, (r) => r.status = "已完成").length AS "已完成"
FROM "kb/实验"
GROUP BY chapter
SORT chapter ASC
```

按运行状态分布（✅ 已跑通 / 📖 待复现）：

```dataview
TABLE WITHOUT ID
  icon AS "状态",
  length(rows) AS "数量"
FROM "kb/实验"
GROUP BY icon
SORT length(rows) DESC
```
